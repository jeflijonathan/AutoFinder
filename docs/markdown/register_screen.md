# Register Screen

## Description

The Register Screen allows new users to create an account within the system. It features a secure form designed to collect essential credentials and user information, ensuring all data complies with validation rules before an account is successfully created.

## Assets

1. Background: `images/background-1.png`

## Features

1. **User Registration Form:** Fields for Email, Username, Phone Number, Password, and Confirm Password with integrated real-time validation.
2. **Input Validation:** Prevents form submission if fields are empty, if the email format is invalid, or if the password confirmation does not match.
3. **Loading State Indicator:** The register button switches to a loading state during the API request to prevent duplicate submissions.
4. **Login Redirection:** A quick link at the bottom for existing users to navigate directly to the Login Screen.
